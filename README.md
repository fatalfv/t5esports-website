# T5 Esports Website

Static Fortnite esports website with a premium dark esports design inspired by modern organization websites.

## Run
Open `index.html` directly, or use VS Code Live Server.

## Deploy
Works on GitHub Pages, Cloudflare Pages, Netlify, Vercel and normal web hosting.

## Discord
All main Discord CTAs use https://discord.gg/t5esports.

## Customise
Replace the `YOUR PLAYER` entries in `index.html` and replace the placeholder YouTube/TikTok/X links with T5's actual social accounts.
